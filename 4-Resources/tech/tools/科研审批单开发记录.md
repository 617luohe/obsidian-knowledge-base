# 科研审批单开发记录

> 一句话定义：报销单 PDF → 科研审批单 Excel 自动生成工具的实现任务拆解，共 5 个 Issue，已全部完成。

## 依赖图

```
Issue 1 (骨架+配置)
    ↓
Issue 2 (PDF解析)
    ↓
Issue 3 (Excel生成)
    ↓
Issue 4 (主流程)
    ↓
Issue 5 (文档+收尾)
```

## Issue 1：项目骨架 + 模板 + 配置

**类型**：AFK | **依赖**：无

- 创建目录结构 `approval-gen/`
- 复制现有科研审批单 Excel 作为 `template.xlsx`
- 创建 `config.yaml`（项目映射 + 默认路径 + 日补贴标准）
- 创建 `requirements.txt`（pdfplumber, openpyxl）
- 实现 `config.py`：加载配置，提供配置对象
- 实现 `amount_utils.py`：数字转中文大写金额（如 500 → "伍佰元整"）
- 测试覆盖 0~9999.99 范围，含角分、零值等边界

## Issue 2：PDF 解析引擎

**类型**：AFK | **依赖**：Issue 1

- 实现 `pdf_parser.py`：
  - 自动检测 PDF 类型（报销单 / 事前申请单）
  - 提取报销单字段：申请日期、报销金额合计、出差日期
  - 提取事前申请单字段：申请日期、起止日期、出差天数（含头尾）
  - 统一日期格式（兼容 `2026-05-07` 和 `May 4, 2026`）
  - 返回结构化 `ParsedData` 对象
- 金额计算：报销单直接取数 / 事前申请单 天数×100
- 边界处理：日期跨月、金额为 0、字段缺失时给出明确错误

## Issue 3：Excel 模板填充引擎

**类型**：AFK | **依赖**：Issue 1, Issue 2

- 实现 `excel_generator.py`：
  - 读取 `template.xlsx` 为模板（保留格式、合并单元格、边框、字体）
  - 填充字段到指定单元格（A3, B4, D4, B11, E11）
  - 输出文件名：`科研审批单M.D-M.D--姓名.xlsx`
  - 不修改模板原始文件，每次基于模板拷贝写入

## Issue 4：主流程编排

**类型**：AFK | **依赖**：Issue 3

- 实现 `process_pdfs.py` 主入口：
  - 自动扫描 `*年*月报销单/` 目录获取 PDF 列表
  - 已生成对应 Excel 的 PDF 自动跳过（去重）
  - 逐文件解析 → 填充 → 输出
  - 控制台打印处理进度和结果摘要
- CLI 参数：`--dry-run`、`--force`、`--month`、`--files`、`--project` / `--project-code`
- 容错：单个 PDF 失败不影响批量的其他文件

## Issue 5：用户文档 + 收尾

**类型**：HITL | **依赖**：Issue 4

- 编写 `README.md`：安装、配置、使用示例
- 用当月真实 PDF 运行验证全流程
- 创建 `/生成科研审批单` Claude Code 技能定义
- 确认输出格式、文件命名、配置内容
