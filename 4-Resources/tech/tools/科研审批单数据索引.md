# 科研审批单数据索引

> 一句话定义：所有已生成的科研审批单 Excel 文件的数据目录索引，按月追踪报销单输入和审批单输出。

## 数据位置

数据存储在源项目目录中，按月分目录：

```
E:\work_files\projects\财务科研审批单\
├── 2026年4月报销单/        # PDF 输入（10 份）
├── 2026年4月科研审批单/    # Excel 输出（5 份）
├── 2026年5月报销单/        # PDF 输入（7 份）
├── 2026年5月科研审批单/    # Excel 输出（4 份）
├── 2026年6月报销单/        # PDF 输入（7 份）
├── 2026年6月科研审批单/    # Excel 输出（4 份）
├── 2026年7月报销单/        # PDF 输入（9 份）
└── 2026年7月科研审批单/    # Excel 输出（5 份）
```

## 数据目录命名规则

| 目录类型 | 命名格式 | 示例 |
|---------|---------|------|
| 输入目录 | `{年份}年{月份}月报销单` | `2026年7月报销单` |
| 输出目录 | `{年份}年{月份}月科研审批单` | `2026年7月科研审批单` |

## 文件命名规则

| 类型 | 命名格式 | 示例 |
|------|---------|------|
| 报销单 PDF（输入） | `innerTravelReportDoc*(N)*.pdf` | `innerTravelReportDoc(1).pdf` |
| 事前申请单 PDF（输入） | `innerTravelRequsitionDoc*(N)*.pdf` | `innerTravelRequsitionDoc.pdf` |
| 审批单 Excel（输出） | `科研审批单M.D-M.D--姓名.xlsx` | `科研审批单7.5-7.10--李涵彬.xlsx` |

> **注意**：事前申请单（`innerTravelRequsitionDoc`）不生成对应的审批单 Excel，仅作为附件参考。审批单只从报销单（`innerTravelReportDoc`）生成。

## 工作流

```
每月收到报销单 PDF
  → 放入 2026年X月报销单/ 目录
  → 运行 /生成科研审批单 生成
  → Excel 自动输出到 2026年X月科研审批单/
  → 更新本索引
```
