# 科研审批单自动生成工具

> 一句话定义：将境内差旅报销单 PDF（`innerTravelReportDoc*.pdf`）自动解析并填充到科研审批单 Excel 模板，一键批量生成财务审批凭证。

## 概述

每月有 4-8 份差旅报销单/事前申请单（PDF），需要人工逐份提取数据并填入科研审批单（Excel 模板）。这个 Python CLI 工具自动化了整个流程：读取 PDF → 提取关键字段 → 计算金额 → 填入模板 → 输出 Excel。

- **源码位置**：`E:\work_files\projects\财务科研审批单\approval-gen\`
- **技能命令**：`/生成科研审批单`
- **技术栈**：Python 3.10+，pdfplumber，openpyxl
- **运行频率**：每月 1-2 次

## 核心流程

```
PDF (报销单)
  → 自动识别类型（报销单 / 事前申请单）
  → 提取申请日期、出差日期、金额
  → 计算金额（报销单直接提取 / 事前申请单 天数×100）
  → 填入项目映射（默认项目名称 + 编号）
  → 基于模板生成 Excel → 输出到对应月份目录
```

## 命令速查

| 命令 | 作用 |
|------|------|
| `python process_pdfs.py` | 自动扫描所有月份，批量生成 |
| `python process_pdfs.py --dry-run` | 预览模式，只显示提取结果不生成文件 |
| `python process_pdfs.py --force` | 覆盖已有文件重新生成 |
| `python process_pdfs.py --month 6` | 指定月份（如只处理 6 月） |
| `python process_pdfs.py --files a.pdf b.pdf` | 指定文件处理 |
| `/生成科研审批单 生成` | Claude Code 技能调用 |

## PDF 类型检测

| 文件名前缀 | 类型 | 金额规则 |
|-----------|------|----------|
| `innerTravelReportDoc` | 境内差旅报销单 | 直接提取"报销金额合计"字段 |
| `innerTravelRequsitionDoc` | 事前申请单 | 天数（含头尾）× 日补贴标准 |

## 字段映射

| Excel 位置 | 字段 | 数据来源 |
|-----------|------|----------|
| A3 | 申请日期 | PDF 申请日期 |
| B4 | 项目名称 | config.yaml 默认值 |
| D4 | 项目编号 | config.yaml 默认值 |
| B11 | 金额（大写） | 数字自动转中文大写 |
| E11 | 金额（小写） | PDF 提取 / 天数×100 |
| 其余字段 | — | 保留模板格式，留空 |

## 领域术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 报销单 | Travel Expense Report | 出差后提交的报销凭证 PDF，含费用明细和金额 |
| 事前申请单 | Travel Expense Pre-Application | 出差前提交的申请凭证 PDF，无金额字段，按天计算补贴 |
| 科研审批单 | Research Approval Form | 研发项目费用付款申请单 Excel，正式财务凭证 |
| 项目映射 | Project Mapping | 配置文件维护的默认项目名称和编号 |
| 支付项目内容 | Expense Item | 固定为"境内差旅费" |
| 天数 | Trip Days | 出差天数（含头尾），用于事前申请单金额计算 |
| 金额（大写） | Amount (Chinese Uppercase) | 小写金额的中文大写转换，如 500 → "伍佰元整" |
