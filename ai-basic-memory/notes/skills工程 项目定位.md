# skills工程 项目定位

- [info] `E:\workplace\skills工程` 是 luohe **专用于开发 skills 的项目**
- [info] 其中 `my-skills/` 是 **release 版本**（独立 git 仓库，remote: `617luohe/my-skills.git`）
- [info] skills 通过 **skills-manager 统一管理**（GitHub 源 → `~/.skills-manager/skills/` → `~/.claude/skills` junction 生效）
- [info] 该 skills-manager 是 luohe **基于一个 GitHub 开源项目优化后自行打包的程序**（定制版，非官方原版；`skills-manager.exe` 报 ModuleNotFoundError 是打包环境问题，不代表损坏，勿据此建议重装/弃用）
