# batch-curator — 批量知识整理

自动分析 + 批量确认模式：扫描 → 分析 → 计划（一次性确认）→ 执行 → 索引 → 归档。

## 一、6 阶段流水线

### ① Scan — 扫描
递归扫描目标文件夹（默认 `raw/`），识别可处理文件。

支持格式：`.md` `.txt` `.csv` `.json` `.pptx` `.docx` `.pdf` `.xlsx` `.py` `.js` `.ts` `.png` `.jpg`
- 特殊格式（pptx/docx/pdf/xlsx）→ 调用对应 skill 提取文本
- 图片 → 移至 assets/ + 简要笔记
- 跳过：隐藏文件、系统文件、已在 7-Sources/ 中的文件

### ② Analyze — 分析（只分析不写入）
对每个文件分析以下维度：

**笔记类型推断** — 优先级：已有 frontmatter > 文件名信号词 > 内容结构 > 默认 `type/resource`
- 概念/术语 → `4-Resources/{domain}/`（tpl-resource）
- 外部来源 → `7-Sources/`（tpl-source）
- 项目相关 → `2-Projects/`（tpl-project）
- 会议记录 → `2-Projects/{项目}/notes/`（tpl-meeting）

**领域推断** — 优先级：已有 domain 标签 > 关键词匹配 > 路径推断 > 已有笔记关联 > 默认 `domain/uncategorized`
- 关键词参考 `9-System/标签体系.md` 中的领域映射
- 匹配多个领域时取前 2 个

**概念提取**：每文件提取 3-8 个关键术语（专有名词/方法名/框架名优先）

**去重检查**：搜索 vault 标题相似度 > 80% → 标记重复；50-80% → 标记相关

每文件输出分析卡片：类型、领域、关键概念、语言、目标目录、已有相关笔记、去重状态。

### ③ Plan — 生成计划（一次性确认）
汇总分析结果，展示表格（文件→笔记类型→目标路径→领域→操作）。用户可在此调整任何字段。

### ④ Execute — 批量生成
**新笔记**：标题 + frontmatter（title/tags/created/status:draft）+ 按类型附加属性 + 自动 wikilink + `## 相关` + `## 来源`
**更新已有**：追加不覆盖，保留手动属性，更新 `updated`，展示 diff 确认

### ⑤ Index — 更新索引
- 已有 MOC → 追加新笔记链接（`- [[笔记名]] — 描述`）
- 某领域 ≥ 3 篇且无 MOC → 建议创建（用 tpl-MOC 模板）
- 新 MOC → 更新 `🏠 知识库入口.md` 导航
- 原则：只增不删，保持原有组织结构

### ⑥ Archive & Report — 归档 + 报告
- 原始文件移至 `7-Sources/{project}/`（同名加序号后缀）
- 输出处理报告：扫描/新建/更新/归档/跳过 统计 + 新建文件列表 + MOC 变更 + 后续建议

## 二、标签规范

参考 `9-System/标签体系.md`。必须：`type/` + `domain/` + `status/draft`。AI 推断内容标注 `> [!ai-guess]`。

## 三、快捷模式

用户提供完整参数时跳过逐阶段确认 → 计划阶段给一次总确认 → 冲突时暂停。

## 四、边界处理

| 情况 | 行为 |
|------|------|
| 空文件夹 | 提示无文件，建议放入文件 |
| >20 个文件 | 建议分批，询问是否继续 |
| 文件读取失败 | 跳过，标记未处理 |
| 二进制文件 | 选项：仅归档/跳过/调用对应 skill |
| 用户取消 | 展示已完成进度，支持继续/回滚 |
| 标题冲突 | 相似度 >80%→跳过；50-80%→加序号+双向链接；<50%→加序号后缀 |
| 领域不明 | 用 `domain/uncategorized`，报告中提示手动分类 |

## 五、安全规则

- 不自动删除：始终归档到 7-Sources/，不删除原文件
- 写入前确认：默认模式阶段③必须确认
- 只追加不删除：更新已有笔记时保留所有原有内容
- 冲突不跳过：标题冲突/去重相似时暂停询问
