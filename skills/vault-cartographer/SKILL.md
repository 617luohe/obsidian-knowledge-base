# vault-cartographer — 知识库制图

## 一、MOC 生成与更新

### 新建 MOC
某领域 ≥5 篇笔记且无 MOC 时：确定范围 → 按主题聚类 → 用 `tpl-MOC.md` 生成（核心概念/进阶主题/相关项目/来源参考）→ 写入 `1-Atlas/MOC-{领域}.md`

### 更新 MOC
读取 MOC → 搜索最后更新后新增笔记 → 检测失效链接 → 生成 diff（➕新增/➖失效/✏️描述过时）→ 确认后更新

## 二、知识聚类发现

分析链接关系 → 找出互链密集但缺 MOC 的笔记群落 → 推荐创建新 MOC

## 三、链接分析

- **中枢笔记**：入链 Top 20（记入链数/出链数/confidence）
- **入口笔记**：入链少、出链丰富的优质新笔记 → 推荐"本周精选"
- **不对称检测**：A→B 但 B↛A 建议双向链接；MOC 声称覆盖某领域但笔记遗漏

## 四、导航健康

- **长路径**：入口到笔记 ≥4 跳 → 建议快捷链接
- **死胡同**：出链=0 但有内容 → 建议添加链接
- **目录漂移**：domain 标签与实际目录不一致 → 建议统一

## 五、图谱报告

按需输出整体报告：总笔记数/链接数/平均链接/MOC数/孤岛/长青 + 领域分布 + 链接热力图 + 改进建议
